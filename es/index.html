Cómo gestiono un proyecto

El proceso que sigo en Coraje y Esperanza, desde la primera reunión hasta la entrega.

  1. Reunirme con el cliente

    Dirijo las reuniones y mantengo la relación, para tener clara la necesidad real.

  2. Levantar requisitos

    Requisitos funcionales, no funcionales y de seguridad, acordados directamente con el cliente.

  3. Definir módulos e historias

    Divido el sistema en módulos y escribo las historias de usuario de cada uno.

  4. Planificar sprints

    Prioridades y sprints gestionados en YouTrack.

  5. Construir y entregar

    Desarrollo el sistema y entrego valor de forma incremental a un cliente real.
