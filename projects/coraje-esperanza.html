Coraje y Esperanza

Management system for a day center: human resources, accounting, inventory, occupational therapy and portals for families and beneficiaries.

My role: I sourced the client, run the meetings with them, defined the modules, gather functional, non-functional and security requirements, write the user stories and manage sprints and priorities in YouTrack. I also develop the system and own the technical and product decisions.

Home, profile and notifications are shared by all roles. The .NET 10 API is organized in layers (API, Application, Entities and Infrastructure) and the React frontend is split by module, with built-in guided tutorials and a help center.

What the video shows

  • Tutorials and help: step-by-step guided tour the first time each screen is opened, and a help center with search and a "Show me how" option.
  • Preferences: light or dark theme saved in each person's account.
  • User management (HR): creating a test account with a role and permissions; the temporary password is shown only once.
  • Accounting and donations: accounts per fund, transactions, economic summary, current accounts and donation receipts.
  • Inventory and warehouse: low-stock alerts and traceability.
  • Occupational therapy: beneficiaries, interventions, indicators per skill and daily attendance.
  • Role-based access: each role (HR, accountant, therapist) sees only the modules that apply to it.
