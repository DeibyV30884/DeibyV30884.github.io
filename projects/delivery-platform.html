Internal Delivery Platform

Application for a restaurant courier service: orders with live tracking, a real-time map and delivery confirmation with a code.

Origin: I identified the operational need and built the application end to end.

4
role-based portals
8

10
database tables

Notice: Users, orders, restaurants and amounts in the video are demo data; they do not correspond to real people or businesses. Note: the interface shown in the videos is in Spanish.

My role and scope

Technologies
.NET 8 (API), React, Tailwind, Leaflet and SQL Server
Security
JWT authentication and role-protected routes
Roles
Customer, restaurant, courier and administrator

  • Confirm order with map
  • Live tracking
  • History and profile

Restaurant

  • Incoming orders and assignment
  • Product management
  • Courier map
  • Profile

Courier

  • Profile

API

  • Administration

  • Couriers

.NET 8 API and a React frontend with Tailwind. Maps use Leaflet and the frontend routes are protected by role with JWT.

What the video shows

  • Customer: searches restaurants, picks a product, confirms the order with the address on a map, sees the shipping cost and total, and follows the order.
  • Restaurant: receives the order, accepts it, assigns an available courier and checks the courier map and product management.
  • Courier: accepts the order, sees the route on the map with directions and confirms delivery with the customer's code.
  • Administrator: statistics by period, user management and balance top-ups.
