How I run a project

The process I follow on Coraje y Esperanza, from the first meeting to delivery.

  1. Meet the client

    I run the meetings and keep the relationship, so the real need is clear.

  2. Gather requirements

    Functional, non-functional and security requirements, agreed directly with the client.

  3. Define modules and stories

    I split the system into modules and write the user stories for each one.

  4. Plan sprints

    Priorities and sprints managed in YouTrack.

  5. Build and deliver

    I develop the system and deliver value incrementally to a live client.
